## Summary
To run real (not simulated) end-to-end pipeline tests while the user is remote,
we need deterministic human-in-the-loop decisions without Slack. Added a
test-only "autopilot" that injects approve / reject / changes / idle decisions
into the validation gate. Unset or `idle` → complete no-op, so it is safe in
production.

## Changes
- **core/agent_registry/hitl_autopilot.py** (new): reads `HITL_AUTOPILOT` env
  (`approve|reject|changes|idle`); `decision(ticket, stage)` returns a synthetic
  approval dict matching the Slack interactive handler's shape. `changes` flips
  to approve on the second evaluation (modify-then-accept). Per-(ticket,stage)
  counter; `reset()` between runs.
- **core/agent_registry/validation_gate.py**: one-line fallback — after the real
  in-memory Slack approval lookups return None, consult the autopilot.
- **tests/e2e/test_hitl_autopilot.py** (new): 4 fast unit tests (idle escalates,
  approve continues, reject fails, changes-then-approve). Slack monkeypatched.
- **tests/e2e/conftest.py** (new): disable OTEL/Langfuse/LangSmith network export
  so `@observe` nodes don't block on a 5s timeout during tests.
- **tests/e2e/run_scenarios.py** (new): manual real-LLM driver for
  mobile/web/backend/compliance scenarios (deepseek + tight recursion limit).
  Not collected by pytest.

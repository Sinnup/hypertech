# HT-009 — DeepSeek AI Provider Integration

**Date:** 2026-06-16 to 2026-06-17
**Branch:** `feat/HT-009-deepseek-ai-provider`
**Type:** Feature

## Summary

Add multi-provider AI support via Strategy + Registry + Factory pattern in `core/ai/`, enabling
seamless switching between Claude and DeepSeek backends. All 7 agents + intent classifier now use
`get_llm()` instead of hardcoded `ChatAnthropic`. Includes provider auto-fallback with Slack
notifications and Langfuse v4 tracing fixes.

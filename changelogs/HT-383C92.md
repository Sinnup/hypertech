## Summary

Replace pip-based manual dependency management with `uv` (Astral's Python package
manager in Rust). Benefits:

- **10-100x faster** installs vs pip
- **`uv.lock`** — reproducible dependency resolution across all devs/CI
- **`pyproject.toml`** — modern PEP 621 metadata + dependency groups
- **Python version management** — `uv python install 3.13` instead of relying on
  whatever Python is on `$PATH`
- **`.venv` isolation** — per-project virtual environment, no global pollution

## Changes

- **pyproject.toml** (new): PEP 621 project metadata, dependencies from
  requirements.txt, optional dev/test groups
- **uv.lock** (new): Locked dependency resolution — committed for reproducibility
- **.venv/** (gitignored): uv-managed virtual environment
- **CLAUDE.md**: document uv setup + daily workflow
- **requirements.txt**: keep as `uv export` output for Docker/CI compatibility
- **docker-compose.yml**: switch pip install to uv if applicable

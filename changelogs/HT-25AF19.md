## Summary

Add LangSmith tracing alongside existing Langfuse to get LangGraph-native node/edge topology
visualization. LangSmith's `LangChainTracer` callback captures graph DAG structure, node
transitions, state diffs, and conditional edge routing — all things Langfuse's flat OTEL
span tree cannot show. Both systems coexist without interference because LangSmith hooks
into LangChain's callback system while Langfuse uses OpenTelemetry context propagation.

Additionally, migrate Docker runtime from Docker Desktop to Colima (already installed)
to avoid needing Docker Desktop open. Colima uses macOS Virtualization.Framework and is
already running with Docker context set to `colima`.

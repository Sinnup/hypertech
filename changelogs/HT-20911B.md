# HT-20911B — Standardize on LangGraph/LangSmith + live Studio; remove Langfuse

- **Scenario**: feature
- **Agents**: all (tracing/observability)
- **Branch**: feature/HT-20911B (stacked on feature/HT-09FBB3)
- **Created**: 2026-06-25 19:55 UTC
- **Status**: in_progress

## Summary
LangSmith showed no node/edge interactions because the runtime was wrapped in a
custom Langfuse OTEL layer (`@observe` on every agent + a `pipeline_trace()`
root span) that double-instrumented traces and hung the pipeline when the
Langfuse ingest endpoint (localhost:3000) was slow. Per the user's priority —
a visible, real-time, *standard* and replicable workflow graph — Langfuse is
backlogged and the stack is now plain LangChain / LangGraph / LangSmith, with
**LangGraph Studio** for the live node/edge view.

## Changes
- **core/tracing/langfuse.py**: rewritten as a no-op shim preserving the public
  API (`observe` passthrough decorator, `pipeline_trace`, `record_generation`,
  `get_client`, `flush` → no-ops; `get_token_usage`/`sum_token_usage` kept).
- **20 files** (`agents/*`, `core/agent_registry/*`, `core/circuit_breaker/*`,
  `core/routing/*`): `from langfuse import observe` → `from core.tracing.langfuse
  import observe` (the no-op shim). No agent imports the Langfuse package now.
- **core/ai/seed_models.py**: `seed()` is a no-op (kept original below for restore).
- **core/graph/workflow.py**: `make_graph()` factory for LangGraph tooling.
- **langgraph.json** (new): registers the compiled graph as `hypertech` so
  `uv run langgraph dev` opens LangGraph Studio with the live node/edge graph.
- **pyproject.toml / uv.lock**: add `langgraph-cli[inmem]` (dev) for `langgraph
  dev`; also lands the carried `gdown` / `pdfminer-six` runtime deps used by KB
  ingestion.
- **.gitignore**: ignore the `.langgraph_api/` dev cache.
- **CLAUDE.md**: tracing section updated to the standard LangSmith/Studio flow.

## Verification
- `uv run langgraph dev` → boots in ~0.6s, imports `graph_id=hypertech`
  (`./core/graph/workflow.py:make_graph`); `/assistants/search` returns the
  `hypertech` assistant; graph schema exposes all 19 nodes. Studio UI:
  `https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024`.
- LangSmith auto-tracing enabled via env (`LANGSMITH_TRACING`,
  `LANGSMITH_API_KEY`, `LANGSMITH_PROJECT`).
- `uv run pytest tests/e2e/` → 9 passed; no OTEL/localhost:3000 hang.
